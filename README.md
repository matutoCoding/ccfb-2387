# 旧铜件涂装配方台

面向道具厂旧铜件涂装的程序化材质工作台：种子驱动、节点编排、实物预览、贴图烘焙。

## 启动

```bash
pnpm install
pnpm dev
```

类型检查与生产构建：

```bash
pnpm build
```

## 四个路由

| 路由 | 页面 | 核心能力 |
| --- | --- | --- |
| `/` | 配方库 | 浏览器 IndexedDB 存档、版本快照、参数级版本对比 |
| `/editor` | 节点编排 | 节点增删复制、拖拽、连线类型校验、循环拦截、撤销重做、种子重建 |
| `/preview` | 实物预览 | 程序生成铜把手、灯光旋转、PBR/单通道查看、UV 接缝定位 |
| `/bake` | 烘焙 | 256~2048 分辨率、分块可取消、通道打包、PNG 下载 |

## 材质约定

- 打包贴图：`R=1.0`、`G=粗糙度`、`B=金属度`、`A=1.0`
- 坏连线（类型不匹配或成环）标红保留，不阻断烘焙，输入端口用 `fallback` 兜底值出图
- 同种子 + 同参数的求值结果确定性一致，噪声基于整数格点哈希

## 目录结构

```
src/
  core/       领域内核：类型、噪声数学、节点定义、求值引擎、校验、历史、存档、diff
  components/ Solid 组件：节点画布、参数面板、局部预览
  three/      Three.js 场景与程序铜把手
  pages/      四个路由页
  styles/     CSS 变量设计系统（8pt 间距、字阶、slate 色阶）
```

## 节点类型

- 输入：UV 坐标、常量颜色
- 噪声：值噪声、FBM 分形噪声（噪声缩放、八度、种子偏移）
- 遮罩：曲率遮罩（边缘/凹缝/反相，采样半径可调）
- 混合：污渍混合（阈值、柔化、强度）
- 映射：颜色渐变、数值曲线（粗糙度/金属度/高度映射）
- 输出：材质输出（基础色、粗糙度、金属度、高度、法线强度）
